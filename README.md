# **Review Decoder: порекомендует ли покупательница эту вещь?**

### **О проекте**

Нужно научить модель определять по английскому тексту, рекомендует покупательница вещь или нет. Для этого необходимо разработать англоязычный текстовый классификатор и сервис, который принимает отзыв и возвращает вероятность recommend / not recommend.

#### **2-й чекпоинт: EDA**

---

#### **3-й чекпоинт: ML-задачи**

- DummyClassifier как baseline.
- TF-IDF + Logistic Regression как обязательная вероятностная линейная модель. LinearSVC допускается как дополнительный эксперимент только вместе с CalibratedClassifierCV, если в сервисе требуется вероятность.
- Нелинейный этап: TruncatedSVD до 100–300 компонент и CatBoost/HistGradientBoosting; sentence embeddings относятся уже к DL-этапу.
- Сравнить модель только по тексту и модель текст + категория одежды.
- Провести анализ наиболее важных слов и типичных ошибок.

---

#### **4-й чекпоинт: Сервисная часть**

- Пользователь вводит английский текст отзыва и при желании выбирает категорию одежды.
- Сервис возвращает вероятность рекомендации из Logistic Regression либо из отдельно откалиброванного классификатора; необработанный decision score LinearSVC нельзя показывать как вероятность.
- Дополнительно можно показывать несколько слов, которые сильнее всего повлияли на прогноз линейной модели.
- Сервис должен использовать тот же preprocessing pipeline, который применялся при обучении.
- Добавить ограничения на пустой и слишком длинный ввод.

#### **6-й чекпоинт: DL-задачи** 
- Обязательный DL-вариант: заранее зафиксированные и кэшированные преподавателем sentence embeddings + небольшой MLP; обучение большой языковой модели не требуется.
- Fine-tuning DistilBERT допускается только как расширение при наличии GPU и времени.
- Сравнить нейросетевой подход с TF-IDF + Logistic Regression по тем же метрикам.

### **Метрики качества**
- Macro-F1.
- F1 для класса not recommend.
- PR-AUC, если класс not recommend объявлен положительным при расчёте метрики.
- Дополнительно — ROC-AUC и confusion matrix.

### **Ожидаемый результат**

- Сравнение TF-IDF baseline, нелинейной модели и DL-подхода.

- Интерпретация слов и типов отзывов, на которых модель принимает ошибочные решения.
