Review Decoder: порекомендует ли покупательница эту вещь?


## **О проекте**

Нужно научить модель определять по английскому тексту, рекомендует покупательница вещь или нет. Для этого необходимо разработать англоязычный текстовый классификатор и сервис, который принимает отзыв и возвращает вероятность recommend / not recommend.

### **Данные**

Используется Women's E-Commerce Clothing Reviews: 23486 анонимизированных англоязычных отзывов, категории одежды и готовая бинарная метка Recommended IND. 
Ссылка на датасет: https://www.kaggle.com/datasets/nicapotato/womens-ecommerce-clothing-reviews
